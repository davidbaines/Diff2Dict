## Conventions

- Be Brief in all interaction with the user.
- Don't say the same thing more than one way.
- Never use an em dash in prose, in chat replies, documentation, code
  comments or commit messages. Do not substitute a hyphen for one either.
  Instead use the word or words that make the meaning explicit (because,
  which, so, that is, namely, therefore ect.) or split the sentence in two.
- Use uv for environment and dependency management.
