# Data

Verse-per-line (vref) text of the Open English Bible, which is public domain.

| File | Edition | Source file |
|---|---|---|
| `oeb-british.txt` | Commonwealth spelling | `eng-engoebcw.txt` |
| `oeb-american.txt` | US spelling | `eng-engoebus.txt` |

Both files come from the corpus folder of <https://github.com/BibleNLP/ebible>,
downloaded on 2026-09-30. Line N of each file is the same verse, and verses
missing from this partial translation are blank lines.
